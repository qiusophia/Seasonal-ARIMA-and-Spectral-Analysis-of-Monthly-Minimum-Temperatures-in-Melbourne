# Seasonal-ARIMA-and-Spectral-Analysis-of-Monthly-Minimum-Temperatures-in-Melbourne
Forecasting Melbourne's monthly minimum temperatures (1981–1990) in R. I compared a hand-built SARIMA to auto.arima on a held-out year, and SARIMA(2,0,0)(0,1,1)[12] won with about 20% less error. Spectral analysis confirms that one annual cycle drives nearly everything.
